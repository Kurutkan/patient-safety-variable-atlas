# Patient Safety Variable Atlas

Interactive map of the independent, dependent, mediating, moderating and control variables tested in 1,638 quantitative patient safety studies indexed in Web of Science Core Collection.

- **Atlas**: click any variable to see its predictors, outcomes, mediators, moderators and the studies behind each link.
- **Model builder**: pick an outcome; see known predictors, mediators and moderators, plus untested mediation paths, distal predictors and candidate moderators.
- **Gap map**: category-by-category matrix of how many studies tested each type of relationship.

Interface in English and Turkish. Data: `atlas_data.json`; full extraction workbook: `PS_Variable_Atlas.xlsx`.

Live: https://kurutkan.github.io/patient-safety-variable-atlas/ · Host page: https://healthtopic.org
